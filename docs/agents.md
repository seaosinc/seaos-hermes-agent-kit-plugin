# エージェント

[← README に戻る](../README.md)

## それぞれの仕事

頼みごとは、いつも **operator** に伝えます。operator が仕事をカードにし、
内容に合うエージェントへ自動で振り分けます。自分で担当を選ぶ必要はありません。

| エージェント | 仕事 | 向いている頼みごと |
|---|---|---|
| **operator** | ユーザーとの窓口。依頼を受けて結果を報告する | すべての頼みごとの入口 |
| **fixer** | 詰まりを解決し、完了を判定する | （直接は頼まない。止まった仕事を動かす） |
| **developer** | 実装・検証・PR 作成。CI とレビュー指摘の解消まで | 「機能を足して PR を出して」「テストが通るように直して」 |
| **senior-developer** | 難度の高い実装。セキュリティと品質も見る | developer が詰まったとき、設計判断が要るとき（自動で回されます） |
| **handler** | 外部サービスの読み書き（GitHub / Backlog ほか） | 「この PR のレビュー指摘をまとめて」「課題を完了にして」 |
| **provisioner** | この PC に、チームが使う道具（Docker など）を揃える | 「Docker を入れて」（足りなければ自動でも動きます） |
| **recruiter** | エージェントそのものを新設・改修する | 「請求書チェック専用のエージェントがほしい」 |
| **broker** | 外部エージェントとの連携 | 他の AI エージェントに仕事を依頼するとき |
| **avatar** | 画面を操作する（人が呼んだときだけ動く） | Hermes Desktop で avatar を選んで直接頼む。自動では動きません |

## 選び方

**迷ったら全部有効のままで構いません。** 使われないエージェントは、何もせずに待っているだけです。

外すと便利なのは次のような場合です。

| こういうとき | 外してよいもの |
|---|---|
| コードは書かせない | developer / senior-developer（Docker も不要になります） |
| GitHub・Notion・Backlog を触らせない | handler |
| エージェントを増やす予定が無い | recruiter |
| 他の AI エージェントと連携しない | broker |
| 画面操作をさせない | avatar |

**operator と fixer は外せません。** チーム全体がこの2つを前提に動いているためです。

外したエージェントには仕事が振られなくなり、他のエージェントの説明からも名前が消えます。

## 外す・戻す

SEAOS 画面の「エージェント」で、行の先頭のチェックを切り替えます。

**外すとき**、そのエージェントが既に導入済みなら確認が出ます。

- **「記憶とセッションも削除する」にチェックしない**：エージェントの記憶は残ります。あとで戻すと、そのまま続きから使えます
- **チェックする**：記憶ごと削除します。**元に戻せません**

進行中の仕事を抱えているエージェントは外せません。終わってから外してください。

**戻すとき**はチェックを入れて **「エージェントを反映」** を押します。

## 足りない道具を揃える（provisioner）

エージェントが使う道具のうち、次の2つは Hermes に含まれていません。

| 道具 | 必要になるエージェント |
|---|---|
| Docker | developer / senior-developer（作業用の箱を使う）、operator（共有の記憶） |
| Node.js | handler（Notion などの読み書き） |

provisioner を有効にしていると、**足りない道具を自動で見つけて入れます**（1時間ごとに確認）。
SEAOS 画面の **「この PC」** で状態を見られます。

入れる途中で **管理者の承認** が必要になったら、provisioner が止まって、operator が Slack で知らせます。

- macOS：ターミナルを開き、案内されたコマンドを貼り付けて実行します（パスワードは Mac のログインパスワード）
- Windows：画面に出る「このアプリがデバイスに変更を加えることを許可しますか？」で「はい」を押します
- Docker Desktop は、初めて起動したときに利用規約への同意が求められます

終わったら、Slack でその旨を返してください（またはカードの「再開」）。provisioner が続きを進めます。

provisioner が入れるのは Docker と Node.js だけです。それ以外を入れてと頼んでも断ります。

## エージェントを増やす

operator に「◯◯ をする専用のエージェントがほしい」と頼むと、operator がいくつか質問したうえで、
recruiter が作って導入まで済ませます。

この PC で作ったエージェントは、一覧で **「この環境」** の印が付きます。

- **この PC の中にしかありません。** PC を入れ替えると消えます
- **「共有」** を押すと、このリポジトリに取り込むための Pull Request を作ります（GitHub の `gh` コマンドが必要です）
- **「削除」** で消せます（配られてきたエージェントは消せないので、チェックを外してください）
